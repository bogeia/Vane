## 变更范围

按照用户确认的首页方向统一全站界面，涵盖精选、全部动态、搜索、热点、主题索引与详情、日报目录与详情、资料详情、事件时间线、收藏、我的、关于、Agent 接入、更新日志及错误状态。具体设计规则见根目录 `DESIGN.md`。

所有页面继续使用原有 React 路由和数据接口。变化集中在设计令牌、各组件 CSS、资料元信息与操作布局、右栏、语义标题、Logo 引用和导航滚动时机。未修改后端、DTO、领域模型、仓储、Wire 或数据库；无新增运行依赖。

Logo 使用原有 `/icon.svg`，该文件与基线的 SHA-256 相同：`8a0d136187b6db8c76e3c0f630ff28cb446aec2dc40118422ee4c2ba9d5337c3`。其他应用图标未修改。

## 调用链与契约检查

- 列表保持 `Feed / useFeed` 的分类、分页、查询取消、只看未读及阅读位置逻辑；详情仍使用 `/api/items/:id`，事件使用 `/api/stories/:id`。
- 主题与日报沿用共享读取；宽度不超过 1180px 时不渲染右栏，也不为其额外读取热点或主题。
- 收藏与已读继续保存于当前浏览器；原文链接、搜索高亮、键盘快捷键和 RSS 地址保持原有行为。

## 指定模型独立验证

- **GPT-6.1-Terra**：独立 worktree 中运行单元测试、构建和 96 组浏览器检查；核对 Logo 字节、主要对比度、焦点及截图。最终提交再次运行右栏与状态检查通过。
- **GPT-6-Luna**：独立 worktree 中验证复杂阅读、导航及共享请求；执行基线对照，验证最终修复与生产构建。

验证发现并处理：

1. 新布局下导航偶发先显示旧滚动位置，再回到顶部。基线 5/5 通过，新布局初版 4/5；改为 `useLayoutEffect` 后主线程与 Luna 各自 5/5 通过。
2. 右栏初始顶部为 32px，旧高度限制只扣除 40px，底部余量不足。改为扣除 64px 后，完整右栏检查通过。
3. 新浏览器夹具的热点 ID 重复，触发 React key 警告。改为唯一 ID，并加入控制台 error 检查。
4. 共享读取测试在开发模式下假定热点请求恰好一次，但 React `StrictMode` 对非共享热点 effect 的重复运行会被路由夹具记录两次。基线和改版各 2/2 同样失败；真正共享的主题、日报请求断言通过。未为此改写产品读取逻辑，完整用例在 production preview 通过。
